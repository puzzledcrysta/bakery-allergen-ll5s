# 换线清场审计字段定义

| 字段 | 类型 | 定义 |
|---|---|---|
| 生产链 | 字符串 | 保留前导零，旧名为业务编号 |
| 修订号 | 整数 | 正整数，兼容版本列。最高修订的业务值一致时保留首次原始行 |
| 提交时间 | RFC 3339 时间 | 必须含偏移量，统一为 UTC，版本裁决以修订号为准 |
| 换线记录 | 业务文本 | 必填，按业务段解析 |
| 配方申报 | 业务文本 | 必填，按业务段解析 |
| 原始备注 | 字符串 | 可空，可内含换行 |
| 外部记录值(可放行批) | 十进制数 | 参照值。真实零值与找不到键分别表示 |
| 范围 | 字符串 | 三列外部账专用：`产线` 行为逐链参照，`班次` 行只登记班次总额 |

外部账支持两种表头：两列 `生产链,外部记录值(可放行批)` 仅逐链对账；
三列 `生产链,范围,外部记录值(可放行批)` 同时承载逐链参照与唯一一条班次总额行，
重复登记班次总额报 `SHIFT_CONFLICT`，范围取值不在 `产线/班次` 报 `SCOPE_UNKNOWN`。
样例见 `sample_data/external.csv`（两列）与 `sample_data/external_shift.csv`（三列）。

记录写作 分钟,产线,批次号,动作,备注。清场备注 PASS 才清除该线残留。生产备注为以加号连接的过敏原，未声明的残留导致该批扣留。

空字符串、`N/A`、`-`、`NULL`、`未知` 均拦在必填字段。`无` 可以表示空集合，按具体业务字段解释。
逐行记录保留物理起始行号。JSON 的计量值为十进制字符串。

## 产线与班次结论

换线裁决为每条生产链返回 `line_rollup`：按产线汇总 `releasable`（可放行批）、
`produced`（生产批）、`held`（扣留批）。运行级 `line_rollup` 再跨生产链合并。
对账结论 `book.shift` 给出班次标识、内部可放行总额、外部班次总额、差值与逐产线明细，
状态码为 `SHIFT_MATCH` / `SHIFT_DELTA` / `NO_SHIFT_TOTAL`。
放行边界 `release_boundary` 逐产线登记本次放行数，状态为
`放行` / `部分放行` / `暂缓` / `待确认`，并汇总 `release_total`、`pending` 与
`within_shift_cap`。工作台与导出共用同一份结论。

## 流水线记录

运行清单保存来源和外部账的 SHA-256、规则版本、耗时、计算参数和创建时刻。
影子版本与重复行保留原始字段。复核与放行边界均按版本追加，旧版本提交返回 409。

运行指纹只取决于规则版本和两份输入哈希：重跑同一输入命中同一运行，
边界记录原样保留；任何写入前校验失败都不会改动既有结果与原始依据。
导入原文件时指纹取源字节，编辑预览后以提交的 UTF-8 文本计算。

# 换线清场审计

面向中央厨房质量主管。按时间检查过敏原残留，只有匹配产线且验证通过的清场才能解除前序过敏原。复算后按生产链核对独立清单，查看单据证据和差值，再登记复核结论。

## 启动

```sh
docker compose up --build
```

默认访问 http://localhost:18291。
打开工作台，点击运行即可使用内置的班次样例。选择导入可以换成自己的来源与独立账 CSV。
样例在 `sample_data/`，`shift.csv` 有分页表头、冲突修订、坏行、空值哨兵与业务拒绝，`external.csv` 有单边与数值差异。
`external_shift.csv` 是三列形态外部账：逐链参照之外只登记一条班次总额，演示多产线共供一班的两级对账。
端口可通过 `APP_PORT` 覆盖。运行记录、复核历史与放行边界保存在 `ledger` 卷。

## 操作

- 在换线裁决展开业务证据，核对原始字段与计算项，并查看每条生产链的产线可放行汇总。
- 在隔离裁决逐行检查原因。独立对账对比外部账、列出逐链差值，并在同一视图给出班次总额与逐产线证据。
- 在独立对账的放行边界逐产线登记本次放行数：超产线可放行数或外部班次总额会被拒绝，
  待确认产线保留，可先部分放行赶排产。
- 在批次复算重跑当前输入。在交付复核提交带版本意见，并导出证据包。
  工作台与证据包共用同一份班次/产线对账结论；重跑不新增待确认、不丢记录，
  核对失败时旧版可放行结果与原始依据保持不变。
